À propos

Claude-Prime est un site HTML statique publié sur Cloudflare Pages. Son code source est disponible sur le dépôt GitHub Claude-Prime.

Technologies utilisées

  • HTML et CSS, sans framework ni police téléchargée ;
  • un peu de JavaScript, exécuté dans le navigateur : salutation selon l'heure sur l'accueil, filtre et recherche sur la page des outils.

Les pages ne chargent aucune ressource depuis un autre domaine.
