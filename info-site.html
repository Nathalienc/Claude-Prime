Technologies

Pages HTML avec une feuille de style partagée. Un peu de JavaScript s'exécute dans le navigateur : la salutation selon l'heure sur l'accueil, le filtre et la recherche sur la page des outils.

Polices

Le site utilise les polices déjà installées sur votre appareil : aucune police n'est téléchargée.

Ressources externes

Aucune. Les pages ne chargent aucun fichier depuis un autre site.

Hébergement
