Organisation des pages

Chaque page suit le même ordre :

  1. un lien « Aller au contenu », visible à la première pression sur la touche Tab ;
  2. l'en-tête, avec le nom du site et le menu principal (Accueil, Outils de vibe coding) ;
  3. le contenu de la page ;
  4. le pied de page, avec les liens Contact, Aide, Info site, Accessibilité, Cookies / Données personnelles et Mentions légales.

La liste de toutes les pages est dans le plan du site.

Utiliser la page « Outils de vibe coding »

  • Les boutons de catégorie affichent uniquement les outils de la catégorie choisie.
  • Le champ de recherche filtre les outils par nom, usage ou conditions d'accès. Le nombre de résultats s'affiche à côté.
  • Le nom de chaque outil est un lien vers son site.

Naviguer au clavier

  • Tab passe au lien, bouton ou champ suivant ; Maj + Tab revient au précédent.
  • Entrée ouvre le lien sélectionné.
  • L'élément sélectionné est entouré d'un contour.

Agrandir le texte

Utilisez le zoom du navigateur : Ctrl et + pour agrandir, Ctrl et 0 pour revenir à la taille normale (Cmd au lieu de Ctrl sur Mac).
